# Cursor · 卡世界小程序前端任务清单

仓库基准：现有**已创建**的微信小程序工程（及必要时 `shared/player-card`）。  
视觉 / 交互对照：本包 `h5-原型/`（先本地打开 `index.html`）。  
页面路径以 `小程序页面映射.md` 为准。

---

## 产品约束（写进代码注释也行）

- [ ] 载体是**小程序**，不是再做一套服务号 H5 主路径；服务号只做「我的卡」入口。
- [ ] 文案：相识 / 开包 / 卡池 / 抽 → **签约 / 入队 / 建档**；检索工程内旧词并替换。
- [ ] **禁止**实现或暗示随机 gacha、概率表、稀有度爆率、随机开包 UI。
- [ ] 签约揭晓可保留 **Cosmos 箔光翻面**，话术为「签约揭晓 / 档案展开」。
- [ ] 蜂蜜无充值入口；会员可展示，未成年账号不展示自动续费开关。
- [ ] 默认组阵 **5v5 新手场**；8 / 11 编制仅作解锁态 UI（接后端）。

---

## A. 工程与路由

- [ ] 新增 / 对齐 pages：`pages/card/main`、`album-sign`、`lineup`、`battle-log`（及可选 battle / 分享页）。
- [ ] 配置三 Tab：主卡 / 卡册·签约 / 组阵（见映射文档 tabBar 草图）。
- [ ] 深色玻璃气质：半透明面板、金点缀；对齐 `h5-原型/css/app.css`。

---

## B. 主卡页（`pages/card/main`）

- [ ] 移植大卡布局：熔金 FUT 框 + 中性数据（出场/进球等，避免贬损性「能力羞辱」文案）。
- [ ] 接入 **Cosmos / Nebula 箔光**：参考 `css/holo-cosmos.css` + `js/holo.js`；小程序用 CSS 变量 + touch；能接陀螺仪则接，否则跟手触摸即可。
- [ ] **禁止**用整页截图静态图冒充跟手箔光；分享海报可另导静态帧。
- [ ] 成长印记位（可先 mock 3 种）。
- [ ] 快捷入口：「去组阵」「去签约」跳对应 Tab。
- [ ] 「分享主卡」：生成海报（真名真颜须已授权；未授权用号码/卡通——产品红线）。

---

## C. 卡册·签约（`pages/card/album-sign`）

- [ ] 卡册网格：主卡标识 + 已签约球员卡；空态文案引导「每日免费签约」。
- [ ] 顶部「每日免费签约」按钮；剩余次数展示（接 `GET` 配额）。
- [ ] 签约揭晓组件：保留翻面 / 箔光；文案改为签约成功 / 入队建档；**去掉**「相识包」「开包」品牌条。
- [ ] 成功横幅 →「去组阵」。
- [ ] 定向签约入口（位置包 / 技能包）：UI 标明「同城确定性定向签约次数」，**不要**做成转轮抽卡。

---

## D. 组阵（`pages/card/lineup`）

- [ ] FUT 球场 5 人位（1 门将 + 4 场上）；对齐原型 `pitch` / 占位交互。
- [ ] 从卡册选人填位；保存阵容（`POST lineup`）。
- [ ] 「发起轻挑战」：满编才可点；进入轻对战流程（VS → 揭晓 → 战报）。
- [ ] 分享挑战条：用当前阵容应战分享者阵容（不上硬榜说明）。
- [ ] 编制切换 UI 预留：免费 5 / 已购社区 8 / 城市 11（未解锁灰态 + 说明）。

---

## E. 轻对战与战报

- [ ] 移植原型 battle-phase：VS 双方卡面摘要 → 比分揭晓 → 结果评论（可弱化「胜负碾压」文案，强调完成度 / 徽章亦可并存）。
- [ ] `pages/card/battle-log`：列表 + 空态；入口在组阵页「战报记录」。
- [ ] 「分享战报」：对外分享默认脱敏（号码，不露未授权真名真颜）。

---

## F. 联调与验收

- [ ] 接 Trae stub：主卡、卡册、同城签约、阵容、对战、战报、会员日签配额。
- [ ] 手测闭环：签约 → 入册 → 组 5 人 → 轻对战 → 战报 → 分享。
- [ ] 全文检索确认无「抽卡 / 开包 / 卡池 / 概率 / 盲盒」上线文案。
- [ ] 对照 Figma V2（若仍有效）：主卡 / 组阵 / 卡册 / 结果；以本包产品改名为准覆盖旧「相识」稿。

---

## 明确不要做

- 随机 pack / gacha / 概率公示页（本产品改为确定性同城匹配）。
- 蜂蜜 RMB 充值页。
- 卡交易、赠送变现、关键词淘卡。
- 把正式赛排位做成新手场默认体验。
