## 建议开工顺序

1. **先本地打开原型**，走通主卡 → 签约/入队 → 组阵 → 轻对战 → 战报闭环（见下方「预览」）。
2. **读** `小程序页面映射.md`：定 pages 与 tabBar，统一「签约 / 入队 / 建档」话术。
3. **Cursor** 按 `Cursor-前端任务.md` 把 `h5-原型` 迁到已有小程序工程（视觉与交互对齐，文案全部改名）。
4. **Trae** 按 `Trae-后端接口草稿.md` 落云函数 / HTTP；签约接口必须**同城确定性**，不要做随机 pack。
5. 联调：主卡拉取 → 每日免费签约 → 保存阵容 → 轻对战 → 战报列表；会员只加**确定性签约次数**。

## 本地预览 H5 原型

推荐起静态服务（避免 `file://` 下字体 / 陀螺仪限制）：

```bash
cd h5-原型
python3 -m http.server 8765
```

浏览器打开：`http://127.0.0.1:8765/`（入口即 `index.html`）。

也可直接用浏览器打开 `h5-原型/index.html`。手机宽优先（约 430px），桌面居中。

**试用路径**：主卡 →「去相识」（落地后文案改为「去签约」）→ 箔光翻面揭晓 → 去组阵凑齐 5 人（含门将）→ 发起轻挑战 → 看战报 / 分享。
