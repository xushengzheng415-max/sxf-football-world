# 小程序页面映射（H5 → 微信小程序）

对照原型：`h5-原型/index.html`（三 Tab + 轻对战浮层 + 战报 + 签约揭晓）。

---

## 1. 视图 → 建议页面

| H5（`data-view` / 浮层） | 建议小程序路径 | 说明 |
| --- | --- | --- |
| `#view-main` 我的主卡 | `pages/card/main` | 大卡 Cosmos 箔光、中性数据、成长印记、快捷「去组阵 / 去签约」、分享主卡 |
| `#view-album` 卡册 / 相识 | `pages/card/album-sign` | 卡册网格 + 每日免费签约入口 + 签约成功横幅；文案全面改为签约/入队 |
| `#view-lineup` 组阵 | `pages/card/lineup` | FUT 球场 5 人（1GK+4）、保存阵容、发起轻挑战、分享挑战条 |
| 轻对战 VS / 揭晓 / 战报面板 | `pages/card/battle`（可与 lineup 同包内子页或组件） | VS 动画 → 比分揭晓 → 战报结果；弱化排位话术 |
| `#battle-log` 战报记录 | `pages/card/battle-log` | 历史轻对战列表；空态引导去组阵 |
| `#meet-reveal` 相识翻面 | 组件 `components/sign-reveal`（挂在 album-sign） | **保留箔光翻面**；标题改为「签约揭晓 / 入队建档」，去掉「包 / 抽」 |

可选二级页（非 Tab）：

| 能力 | 建议路径 |
| --- | --- |
| 主卡分享海报 | `pages/card/share-poster` 或 canvas 导出 |
| 定向签约（位置/技能次数购买说明） | `pages/card/sign-定向` 或会员权益页内区块 |
| 编制解锁说明（8 / 11） | `pages/card/roster-unlock` |

    "borderStyle": "black",

      {
        "pagePath": "pages/card/main",
        "text": "主卡",

      },
      {
        "pagePath": "pages/card/album-sign",
        "text": "卡册·签约",
        "iconPath": "assets/tab/album.png",
        "selectedIconPath": "assets/tab/album-active.png"
      },
      {
        "pagePath": "pages/card/lineup",
        "text": "组阵",
        "iconPath": "assets/tab/lineup.png",
        "selectedIconPath": "assets/tab/lineup-active.png"

`app.json` pages 建议顺序：`main` → `album-sign` → `lineup` → `battle-log` →（可选）`battle` / `share-poster`。

**入口**：服务号自定义菜单「我的卡」→ 跳转小程序上述 `pages/card/main`（或带 `path` 的 URL Link / 半屏）。勿埋在「我的」深层。

## 3. 改名对照表（必须统一）

| 原型 / 旧词 | 落地对外文案 | 备注 |
| --- | --- | --- |
| 相识、免费相识 | **签约**、每日免费签约 | 动作 |
| 相识成功、新卡已入册 | **签约成功 / 入队建档** | 成功态 |
| 相识包、开包 | **档案卡展开 / 签约揭晓** | 动画可留翻面，禁止「包」「抽」 |
| 卡池、抽、抽卡、盲盒 | **同城球员库、定向签约** | 禁用旧词 |
| 去相识 | **去签约** | 主卡快捷入口 |
| 卡册相识（Tab） | **卡册·签约** | tabBar |
| 轻挑战 / 轻对战 | 可保留「轻对战」「新手场」 | 强调非排位正式赛 |
| 样卡 | 可改为「同城样卡 / 演示卡」或正式「签约球员卡」 | 上线接真档 |

**动画**：Cosmos / 箔光翻面**保留**；UI 文案与音效按「档案展开 / 签约揭晓」表述，不表现抽奖机、概率、稀有爆率。

## 4. 编制与玩法档位（映射到组阵页提示）

| 档位 | 人数 | 付费 | 用途 |
| --- | --- | --- | --- |
| 新手场 | **5**（1GK+4） | 免费长期保留 | 原型默认组阵；轻对战主循环 |
| 社区正式 | **8** | 付费解锁编制 | 社区赛报名门槛 |
| 城市 / 区域正式 | **11** | 付费解锁编制 | 市级赛报名门槛 |

组阵页默认 5v5；解锁后可切换编制模板（接口见后端草稿）。
