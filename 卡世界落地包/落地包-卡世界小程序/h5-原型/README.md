# 赛小蜂 · 卡世界 H5 高保真原型（对照用）

路径：本目录 `h5-原型/`（视觉对照；正式主载体为**微信小程序**）。  
气质：深色玻璃页 + FUT 熔金框主卡 + **Cosmos / Nebula 星云箔光**（跟手倾斜）。

> **产品真相**：同城**确定性签约**（非随机开包）。箔光翻面可保留；禁止抽/开包/卡池话术。详见项目根 `现行玩法与废弃说明.md`。

## 如何打开

1. **推荐**：本地静态服务
   ```bash
   cd h5-原型
   python -m http.server 8765
   ```
   浏览器打开 `http://127.0.0.1:8765/`
2. **也可**：直接打开 `index.html`。

手机宽优先（`max-width: 430px`），桌面居中。

## 三页可玩闭环（现行）

```
我的主卡 ──快捷入口──→ 去签约 / 去组阵
     │                      │
     │                      ▼
     │              卡册·签约（每日免费签约 mock，同城确定性）
     │                      │ 签约成功 →「去组阵」横幅
     │                      ▼
     └──────────────→ 组阵（填满 5 人含门将）
                            │
                            ▼
                     发起轻挑战（新手场，非排位）
                            │
                            ▼
                     结果 / 战报 + 分享阵容 / 分享挑战
```

| Tab | 说明 |
| --- | --- |
| **我的主卡** | 大卡 Cosmos 动效；中性数据；成长印记；快捷「去组阵 / 去签约」 |
| **卡册·签约** | 网格小卡；每日免费签约；成功后引导组阵；定向签约入口勿做成转轮抽卡 |
| **组阵** | 5 人阵（1GK+4）；满编可「发起轻挑战」；战报 + 分享 |

样例球员：铁栋泽 / TIE D.Z. / 前锋 / 10。

## 试用路径

1. 主卡 → **去签约** →「免费签约」→「去组阵」横幅。
2. 凑齐 5 人（含门将）→「发起轻挑战」→ 看结果 / 战报。
3. 也可从主卡直接 **去组阵**。
