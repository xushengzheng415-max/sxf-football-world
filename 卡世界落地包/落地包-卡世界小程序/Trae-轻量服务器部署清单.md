## 1. 架构一句话

本机只做**轻量 BFF / 网关**：承接小程序 `wx.request`（登录换票、同城确定性签约/入队、卡册、组阵、轻对战与战报、会员日签配额与定向签约次数），**球员 / 球队主数据仍读现有「赛小蜂足球」后端**；**不以微信云开发作为主库**。

```
[服务号「我的卡」] → [小程序 AppID wxa0ac7d45bcabd140]
                         │  HTTPS（需配 request 合法域名）
                         ▼
              [轻量服务器 = BFF / Gateway]
                         │  只读/受控写：卡世界会话、配额、阵容、战报等
                         ├─→ [现有赛小蜂足球后端] 球员/球队主数据、城市、账号绑定
                         └─→ （可选）本机轻量存储：会话 token、签约游标、阵容快照、战报
```

**不做：** 随机开包 / gacha 端点；微信云开发当主 DB；把球员主档迁到本机。

## 4. 接口清单对照

路径前缀示意：`/api/card-world/`（可按实装改名，但能力必须齐）。对照草稿：`Trae-后端接口草稿.md`。

| 能力 | 方法 / 路径 | 部署验收要点 |
| --- | --- | --- |
| 登录换票 | 小程序 `wx.login` → 网关用 `code` 调微信 `code2session` → 下发自有 token | AppSecret 仅服务端；token 绑定 openid / 球员 |
| 主卡 | `GET …/main-card` | 数据来自主库球员档 + 卡世界展示字段 |
| 卡册 | `GET …/album` | 含 `signQuota`（日免、定向剩余） |
| 同城确定性签约 / 入队 | `POST …/sign-same-city` | **无随机**；同输入可复现；扣配额；跳过已拥有 |
| 定向签约 | 同上，`mode`=`定向_position` / `定向_skill` | filter 必填；扣定向次数 |
| 阵容 | `GET/POST …/lineup` | 免费 5；8/11 未解锁返回 `ROSTER_LOCKED` |
| 轻对战 | `POST …/battle` | 同输入结果唯一；会员不加胜负权重 |
| 战报 | `GET …/battle-log` | 分页列表可用 |
| 会员与日签配额 | `GET …/membership`；日配额发放（登录或定时） | 会员加的是**确定性签约次数**；未成年禁自动续费 |
| 编制解锁 | `POST …/roster-unlock` | 支付走现有方案；本网关记解锁态 |

**明确不上线：**

| 禁止 | 原因 |
| --- | --- |
| `…/pack/open`、`/gacha`、`/draw` | 已取消随机开包 |
| `…/honey/recharge`（RMB） | 无蜂蜜人民币充值 |
| 卡交易 / 赠送变现 | 红线 |
| 按付费加权胜负 | 红线 |

**建议落地顺序（与草稿一致）：**  
main-card + album → sign-same-city（日免）→ lineup(5) → battle + battle-log → membership / 8·11 解锁 → 定向签约。

## 5. 微信侧配置

| 配置项 | 值 / 操作 |
| --- | --- |
| 小程序名称 | 赛小蜂足球世界 |
| AppID | `wxa0ac7d45bcabd140` |
| request 合法域名 | `https://<网关域名>`（**必须**；与证书 CN/SAN 一致，勿带路径） |
| 业务域名 / web-view | 仅当页内嵌 H5 时再配；纯原生页可暂空 |
| 上传 / 下载域名 | 若有卡面图上传下载再配 |
| 服务号入口 | 自定义菜单「**我的卡**」→ 关联本小程序；建议 path=`pages/card/main` |
| 体验成员 / 正式发布 | 联调加体验者；验收通过后再提审发布 |
| 开发阶段 | 工具可临时「不校验合法域名」；**真机与上线必须已配域名** |

登录链路（网关实现）：

1. 小程序 `wx.login` 取 `code`
2. 网关 `POST` 微信 `jscode2session`（`appid` + `secret` + `code`）
3. 网关签发自有会话 token（绑定 openid；若已绑定球员则带上 playerId）
4. 后续 `wx.request` 带 Authorization / Header；**禁止**把 AppSecret 写入小程序

## 6. 与主库对接

| 数据 | 权威来源 | 轻量网关职责 |
| --- | --- | --- |
| 球员主档、球队、城市、账号绑定 | **现有赛小蜂足球后端** | 只读 / 受控查询；用 ID 引用 |
| 卡册归属、签约游标、日签/定向配额 | 网关侧轻量存储（或主库扩展表，由团队定） | 写配额与游标；发放结果可审计 |
| 阵容、战报、会员解锁态 | 网关侧或主库约定表 | CRUD；对战结果确定性落库 |
| 微信 openid / session | 网关换票后自管 | 不落 AppSecret；可映射到主库用户 |

对接检查：

- [ ] 同城池：按主库 `cityCode`（或等价字段）过滤可签约球员
- [ ] 确定性键可落库审计（草稿示例：`deterministicKey`）
- [ ] 主库故障时：只读接口有明确错误码；勿静默降级成随机挑人
- [ ] **不以**微信云开发数据库作为球员/球队主数据源

## 7. 验收标准

真机或体验版，合法域名已生效后逐条打勾：

### 7.1 连通与安全

- [ ] `https://<网关域名>/health`（或等价）外网可达，证书有效
- [ ] 小程序未勾「不校验合法域名」时，`wx.request` 仍成功
- [ ] AppSecret / 主库密钥未出现在前端包、仓库明文、日志完整打印中

### 7.2 登录

- [ ] `wx.login` → 网关换票成功，拿到 token
- [ ] 无效 / 过期 token 返回可识别未登录错误

### 7.3 主卡 / 卡册

- [ ] 主卡展示与主库球员一致（姓名、位置、城市等）
- [ ] 卡册列表可拉取；配额字段可见

### 7.4 同城确定性签约

- [ ] 每日免费签约：同城、扣 1 次日配额、写入卡册
- [ ] **同一规则 + 同一输入**重复调用结果一致（或明确「已拥有则推进游标」的可文档化行为）；代码路径无随机
- [ ] 配额用尽返回 `QUOTA_EXCEEDED`
- [ ] 定向（位置 / 技能）次数可扣减且仍确定性
- [ ] **不存在**开包 / gacha / draw 可调端点

### 7.5 组阵 / 对战 / 战报

- [ ] 保存 5 人阵容成功；未解锁 8/11 时拒绝并 `ROSTER_LOCKED`
- [ ] 轻对战出分；同阵容+同对手+同规则结果一致
- [ ] 战报列表可见刚打的一局
- [ ] 会员不改变胜负权重

### 7.6 会员与入口

- [ ] 会员仅提升确定性日签（等）次数；未成年无法开自动续费（`MINOR_NO_AUTORENEW`）
- [ ] 服务号「我的卡」可进入小程序主卡页

### 7.7 架构红线

- [ ] 球员/球队主数据仍来自现有赛小蜂足球后端
- [ ] 未把微信云开发当作主 DB
